# Card List Capsule

CSS-only vertical glass card stacks with hover lift, scale and radius choreography.

## Usage

```html
<drop capsule="card-list"></drop>
<div class="card-list">
  <article class="glass card-list__item">...</article>
  <article class="glass card-list__item">...</article>
</div>
```

## Features

- Vertical glass card stack layout
- Hover lift and scale animation
- Radius choreography on first/last items
- `.card-list--dense` variant with roomier padding, for fuller cards like blog posts
- CSS-only, no JavaScript required
