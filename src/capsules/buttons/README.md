# Buttons Capsule

88x31 button container for retro-style web badges.

## Usage

```html
<drop capsule="buttons">
  <a href="https://example.com">
    <img
      src="/media/buttons/example.png"
      width="88"
      height="31"
      alt="Example"
    />
  </a>
</drop>
```

## Features

- Flex-wrap container for 88x31 badge buttons
- Glass highlight overlay on each button
- Hover lift + scale animation
