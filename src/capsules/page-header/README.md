# Page Header Capsule

Header wrapper that centers the nav pill and provides responsive layout. Wraps the header capsule via slot.

## Usage

```html
<drop capsule="page-header" data-nav-page="home">
  <li class="nav-pill__item">...</li>
</drop>
```

## Features

- Centers the nav pill in the viewport
- Switches to space-between on mobile
- Configurable via the `data-nav-page` attribute
