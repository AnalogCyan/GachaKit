    Core Concepts

    Capsules

    Self-contained components that bundle their own HTML, CSS, and JS. Drop a <drop capsule="..."> tag into any page and the build system expands it, bundles the styles, and wires up the scripts.

    Drop Syntax

    Compose layouts with declarative <drop> tags. Capsules can nest other capsules, accept data attributes for configuration, and the whole thing recursively expands at build time.

    Liquid Glass

    Frosted transparency, backdrop blur, layered depth, soft light reflections, and bold color accents. Every surface feels physical and tactile without being chaotic.

    Zero Bundler

    One Node.js script. No webpack, no Vite, no complicated config. The build reads your pages, expands drops, bundles capsule stylesheets, and outputs static HTML ready to deploy anywhere.

    Photo Cards

    Polaroid-style photo cards with fullscreen modal capabilities.

    Button Arrays

    Connected-pill button rows with Material-style radius choreography. Hover one and the siblings gently shrink. Stack vertically on small screens.
